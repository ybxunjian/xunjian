# 巡检业务规则

设备与字段的实现来源为 [config.ts](../src/features/inspection/model/config.ts)、[field-rules.ts](../src/features/inspection/model/field-rules.ts)，完整性检查在 [validation.ts](../src/features/inspection/model/validation.ts)。

## 范围与填写

主导航默认顺序为 8#冲渣、皮带、9#冲渣、历史记录；账号可调整顺序，第一项为启动页面。皮带包含 SZ101、SZ201、SZ201-N。

- 数值不显示单位，使用数字键盘，最多两位；未填保留为空，不自动补 0 或 1。
- 黑色实心点表示没有对应点位，不代表异常。状态控件默认正常，可在勾与叉之间切换。
- 泵号保留原生下拉。局部清空仅影响当前泵的编号/四个读数或当前皮带项目，提示提供本次清空的撤销。
- 新建清空填写并把皮带重置到 SZ101，同时写入新版本空白草稿，使清空也能跨设备同步。
- 保存自动生成日期、完整填写时间、UUID 和 ISO `createdAt`；日期、班次、巡检人等纸表栏不另作输入。

产品范围不包含液压站油位、冲渣料斗下料口、SZ201 / SZ201-N 头轮下料口、泵房/管廊排水和卫生等附加事项，也不包含皮带情况、高低速联轴器、头轮气管或尾轮下料口独立勾选卡片。

## 冲渣泵

| 区域 | 设备组 | 泵号 |
| --- | --- | --- |
| 8#冲渣 | 冲渣泵 | 101、102、103 |
| 8#冲渣 | 上塔泵 | 501、502、503 |
| 9#冲渣 | 冲渣泵 | 201、202、203 |
| 9#冲渣 | 上塔泵 | 1#、2#、3# |

每组两用一备，只填写两台运行设备；每台读数为南、北、前轴、机身。

同组重复选择必须交换编号，不能禁用选项：当前为空时取得另一张卡的泵号、另一张清空；当前已有编号时两张互换。实现为 `selectPump`。

“盘根引水槽”控件及其字段仍在代码中，由 `.pump-status-row` 隐藏。该兼容字段不是无引用旧代码，删除前需核验已有数据。

## 皮带

| 皮带 | 当前项目 |
| --- | --- |
| SZ101 | 电机（单输入）、头轮、头增面轮、尾轮 |
| SZ201 | 电机/减速机、头轮、配重东/南、配重西/北、配重、中间滚筒、尾轮 |
| SZ201-N | 电机/减速机、液力耦合器（单输入“液耦”）、头轮、头增面轮、配重东/南、配重西/北、配重、尾轮 |

SZ101 默认方向东/西，其余南/北。电机/减速机用“电机”“减速机”；两组配重分别用东/南、西/北。配重东/南和配重西/北标题前显示实心点，“配重”没有。

## 保存与汇总

保存校验分别列出未选泵号和空白数值。用户可以返回补充，也可明确选择仍然保存。校验覆盖所有设备，不只当前页面；状态字段不作为数值完整性条件。

新保存记录置于列表开头，云端拉取和备份合并按记录时间排序。汇总顺序为皮带、8#冲渣、9#冲渣，只展示已填写读数，泵条目需有泵号。历史显示的月日、年份/星期和填写时分由 [history-record-display.ts](../src/features/inspection/model/history-record-display.ts) 格式化；同日不重复日期，跨日/跨年标明填写日期，完整原始时间仍保留。

## 历史、日历与删除

- 普通列表只有右侧箭头进入详情，卡片与日期不触发跳转；批量模式下整张卡片用于勾选，没有全选入口，勾号退出管理。
- 日历周一为首日，打开时定位最新记录月份；无记录时使用当前月。有记录的日期打开当天第一条记录，其余同日记录从列表进入；无记录日期不可点击。最早记录月不能继续向前。
- 从日历进入详情返回日历，从列表进入返回列表。菜单和分页的运动行为见 [公共 UI 与交互](./ui-components.md)。
- 批量删除与详情删除均为按钮原位二次确认，复用 `deleteRecords(ids)`。改变勾选使批量确认失效；取消保留勾选；确认防重复提交。
- 删除后提示可撤销本次删掉的记录，按 UUID 合并到当前列表，不覆盖随后新增或其他删除。账号巡检页面卸载后撤销提示失效。

## 备份恢复

备份是历史内独立页面，退出清除导入预览，恢复成功返回列表。

- 导出优先系统文件分享，不支持或分享失败则下载；用户取消分享不记为成功。没有历史记录时不导出。
- 导入限制 10MiB，先解析预览新增、重复、无效数量。格式和兼容读取见 [数据与同步](./data-and-sync.md#记录与备份格式)。
- 合并只新增当前列表不存在的 UUID，不替换同 ID 记录；无新增时不执行恢复。
- 覆盖得到备份中的有效目标集合，需明确二次确认；存在无效记录时禁止覆盖。
- 恢复前保存原列表快照，可在五分钟有效期内撤销一次，包括刷新后恢复撤销入口；账号切换不带入其他账号快照。恢复撤销与删除撤销是不同机制。
