# 巡检业务规则

本文件维护产品范围和稳定业务行为。设备来源为 [config.ts](../src/features/inspection/model/config.ts)、[field-rules.ts](../src/features/inspection/model/field-rules.ts)，完整性检查在 [validation.ts](../src/features/inspection/model/validation.ts)。

## 产品范围

主导航默认顺序为 8#冲渣、皮带、9#冲渣、历史记录。账号可调整顺序，第一项作为启动页面；用户已手动选择页面时，延迟加载的偏好不覆盖该选择。

表单仅覆盖下列设备读数，不包含液压站、排水、卫生及附加勾选检查项。旧记录字段的保留规则见[数据兼容](./data-and-sync.md#兼容读取)。

## 填写、保存与汇总

- 读数不显示单位，保留空白，不自动补值；输入使用数字键盘提示和两字符长度限制，当前未额外过滤非数字字符。
- 局部清空只作用于当前泵或皮带项目，可撤销；不覆盖其他项目。
- “新建”清空填写并重置皮带为 SZ101，同时保存新版本空白草稿。
- 保存检查所有设备的未选泵号和空白读数，允许返回补充或明确选择仍然保存。
- 每次保存生成新 ID、日期、填写时间和 createdAt，转到历史列表；保存不清空草稿，不按相同读数去重。

汇总按皮带、8#冲渣、9#冲渣排列，只展示已填读数；泵条目需有编号。历史日期与填写时间分开显示，跨日/跨年保留日期说明，完整原始时间仍可读取。

## 历史与删除

普通列表由箭头进入详情；批量模式整卡勾选，不提供全选。重新进入历史回到列表并清除选择状态。

日历以周一为首日，打开定位最新记录月，无记录时为当前月；最早记录月限制向前翻页。有记录日期进入当天第一条记录，从日历进入详情后返回日历。无法解析日期的旧记录保留在列表和备份，不进入日历。

详情与批量删除均需原位确认；改变勾选会取消批量确认。删除后按 ID 合并撤销本次集合，不覆盖后续修改；账号巡检页面卸载后该删除撤销入口失效。

## 备份恢复

备份位于历史独立页面，退出清除预览，恢复成功回到列表。

| 操作 | 规则 |
| --- | --- |
| 导出 | 有记录时优先系统文件分享，失败或不支持则下载；用户取消分享不记成功 |
| 预览 | 文件最多 10MiB，显示新增、重复和无效记录数量 |
| 合并 | 只新增不存在的 ID，不替换同 ID 记录；无新增时不执行 |
| 覆盖 | 明确二次确认后替换为有效目标集合；有无效记录时禁止覆盖 |
| 撤销恢复 | 恢复前保存快照，五分钟内可撤销一次，刷新后仍可用；账号切换隔离快照 |

备份载荷、旧格式和 ID 校验见[数据与同步](./data-and-sync.md#记录与备份格式)。恢复撤销与删除撤销是不同机制。
