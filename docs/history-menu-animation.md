# 历史记录菜单动画触发规则

保留原有全部动画定义、路径、时长、延迟、缓动、透明度与 pathLength 效果，以及各操作的最终图标。

本文件只约束历史记录菜单。后来明确批准修改的头像气泡、退出登录分列和日历分页，各自遵循 `ui-components.md` 的时间线，不能把本文件解释为所有组件永久禁止调整动画。

1. 一次操作由最终状态负责触发动画，不能先触发普通菜单收起，再触发页面或模式切换。
2. 会使菜单退出的外部操作使用 `data-history-menu-transition="exit"` 标记。当前入口为切换到其他导航页、进入记录详情；点击当前导航项仍沿用原行为。
3. 外部点击处理器忽略带有该标记的操作，由其点击回调更新页面状态，再执行已有退出动画：当前线条直接收缩到中心点并消失。
4. 菜单内部操作沿用原来的更新方式：日历、备份、批量管理、返回和完成均保留原有目标图标，不新增重置状态。
5. 普通外部点击、点击叉号和 Escape 沿用原来的收起行为与触发时机。
6. 动画打断、组件退出、禁止交互和减少动态效果均沿用原有实现，不引入冻结、额外淡出或新动画。

后续新增外部退出入口时，使用同一标记；不要修改动画参数来解决触发顺序问题。

## 当前保留的动画参数

- 功能按钮组：展开和退出均为 240ms，缓动 `[0.22, 1, 0.36, 1]`；进入从右移 24px、缩放 0.86、透明度 0 到正常位置，退出沿原参数返回。切换导航时仍执行这组既有退出动画。
- 图标线条：变形、从中心展开及向中心收缩为 300ms，同一缓动；中线的 `pathLength` 和透明度为 200ms，形成返回箭头时延迟 80ms。叉号退出直接向中心收缩并淡出，不先变三横线。
- 退出时由原 `isPresent` 状态禁止菜单交互；减少动态效果时按原实现直接切换，不新增冻结或其他过渡。
- 菜单处于独立静态 Portal，不参与页面切换位移。详情页没有菜单时使用 `propagate={!selectedRecord}`，避免空菜单阻塞一级页面退出等待；这项规则不代表已修复全部快速导航问题。
