# 公共 UI 与交互

项目中的重复 UI 和交互统一提取为公共可复用组件。相同类型的界面必须从公共组件调用，禁止在业务页面复制一套近似实现；后续修改公共实现一处，应同步影响全部使用位置。

## 组件化原则

- 先识别重复的结构、视觉和交互，再选择 `src/components/ui`、跨业务 feature 组件或业务内部组件作为唯一实现位置。
- 同类组件的布局差异通过语义化属性、variant 或插槽表达，不通过复制组件后分别维护。
- 公共组件负责通用结构、样式、可访问性和交互状态；数据规则、提交请求、存储和业务判断留在调用方。
- 修改公共组件前检查全部调用位置；修改后验证所有使用页面，确保“一处修改、全部同步”。
- 视觉相似但职责不同的组件保持分组独立。例如顶部 4 项主导航与下方 3 项皮带选择分别由 `InspectionTabs` 和 `BeltTabs` 维护，不合并为一个含大量条件的万能组件。

## 调用约定

- `DirectionalViewTransition` 统一历史列表、记录详情、巡检日历和备份页的切换。调用方在进入时设置 `direction=1`，返回时设置 `direction=-1`，不沿用上一次操作方向。前进时旧页左移 14px 淡出，新页从右侧 18px 淡入；返回时旧页右移 18px 淡出，新页从左侧 18px 淡入。`mode="wait"` 先出后入，各 180ms，缓动 `[0.22, 1, 0.36, 1]`；首次挂载不播放，减少动态效果时立即切换。成功导入后关闭备份页也按返回方向处理。公共容器使用 `overflow-x: clip` 裁剪横移动画，避免 18px 位移超过页面 16px 留白而增加文档宽度；纵向溢出保持可见，不创建内部滚动容器，继续使用原来的整页滚动。
- `Sheet` 在调用方的 `AnimatePresence` 中使用；`labelledBy` 必须对应实际标题 ID。当前账号、删除和保存校验均使用独立 `Sheet`；旧嵌套弹窗、额外尺寸和 `overlays` 插槽已无业务调用，已移除。提交中传入 `busy`，业务按钮继续使用 `disabled`。页面滚动锁定、顶层焦点限制、`Esc` 关闭和退出中的交互禁用由公共组件统一处理；退出开始时清除弹窗内部焦点，关闭后也不主动恢复触发按钮的焦点，避免退场期间或关闭后出现可见焦点框。多个弹层在退出或进入期间重叠时，栈仍限制顶层焦点，其余面板进入 `inert` 和 `aria-hidden` 状态。弹层动画、安全区、背景和滚动容器统一在这里维护。
- `TextField` 负责标签、输入框样式、错误关联、错误占位和抖动；`PasswordField` 只组合密码可见性和眼睛按钮。`belowAction` 用于忘记密码等附加操作。
- `PasswordField` 保留原生密码输入语义，通过 `type="password"` / `type="text"` 切换显隐。当前不采用 `-webkit-text-security` CSS 遮罩方案；该方案无法保证密码管理器、iOS 安全键盘和辅助功能与原生密码框一致，未完成真机验收前不得重新引入。
- 邮箱与密码输入框通过公共 `TextField` 统一最小高度 52px、字号 16px；登录、注册、密码恢复与账号内修改密码共同复用，`PasswordField` 不单独覆盖高度。错误提示预留区不计入输入框高度。
- 登录、创建账号、发送重置邮件与密码恢复页的保存新密码按钮最小高度统一为 48px，字号 16px；账号内修改密码的取消和保存仍为 44px。
- 表单纵向间距由 `globals.css` 的 credential/auth 间距令牌维护：以输入框 52/56、认证提交按钮 48/52 的缩小比例为依据，再四舍五入为整数像素（根字号 16px）。普通输入框边缘间距由 32px 变为 30px，保留 24px 的字段错误预留区；普通末尾输入框到认证提交按钮由 44px 变为 41px。账号内三个密码框复用相同字段间距，取消/保存行上方距离同步收紧，按钮本身仍为 44px。Logo 到标题为 19px、标题到说明为 11px、标题区域到表单为 22px、提交按钮到登录/注册切换区为 15px。文字字号、横向间距和页面顶部锚点保持原值；带忘记密码操作的提示行仍保留至少 44px 点击高度，不为严格比例牺牲触控空间。
- `useFieldFeedback.report(errors)` 替换字段错误，递增出错字段的动画序号，并返回是否存在错误。输入变化调用 `clear(field)`；切换表单模式调用 `reset()`。通用密码校验仍使用 `auth-validation.ts`。
- `InspectionTabs` 统一顶部 4 个主导航项，使用蓝色选中态和 `aria-current`。`BeltTabs` 统一下方 3 个皮带选项，使用白色选中态、项间距和 `aria-pressed`。两组视觉与交互独立维护。
- 历史列表采用日期与填写时间分区排版：月日 22px、字重 700，年份和星期 11px；填写时分 15px 灰色、字重 600，说明 11px，主值与辅助信息分别按共享网格行对齐。同日省略重复日期，跨日、跨年明确标注填写日期；只调整显示，保留完整原始记录与无障碍时间说明。卡片至少 88px 高，详情入口圆形可见直径 34px、点击区域 44px。详情底部返回按钮为 48px 高胶囊，删除按钮为 48px 圆形，间距 8px，不使用彩色阴影，沿用现有颜色和动画。
- 历史管理菜单属于巡检业务组件 `HistoryQuickMenu`：日历、备份与恢复、批量删除复用公共 `Button` 的 `ghost` / `icon` 组合，仅显示 21px Lucide 图标，保留 44×44px 透明点击区域和现有间距；无圆背景、边框、阴影、悬停底色或按压缩放。切换入口复用 `ghost` / `icon` 并保留原有反馈。只有切换入口的三横线 / 叉 / 勾 / 左箭头连续线条动画使用业务内 SVG；其余功能图标使用 Lucide。整组展开、收起动画保持原样。
- 样式继续消费 `src/app/globals.css` 的设计变量。`field-shake` 的动画和减少动态效果规则只在这里定义一次。
- 组合 Tailwind 类名统一使用 `src/lib/utils.ts` 的 `cn()`。项目自定义字号 `text-label`、`text-caption`、`text-body`、`text-card-title` 和 `text-title` 已注册为字号类，必须与 `text-destructive`、`text-muted-foreground` 等颜色类同时保留。新增 `--text-*` 字号变量时，必须同步扩展 `cn()` 的 `font-size` 分组并补充回归测试，避免字号类被 `tailwind-merge` 误判为颜色类后删除。
- 巡检数据规则、存储、云同步、密码提交、导入导出和具体确认动作保留在各业务模块中。
- `ConfirmationPopover` 在触发入口下方显示带尖角的非模态确认气泡，复用公共 `Button`，上方为危险确认、下方为灰色取消，均为胶囊形且至少 44px 高。尖角由 16px 正方形旋转 45° 构成，相对气泡外边框外露 10px，上移量按旋转后的几何尺寸计算并计入 1px 边框。气泡宽 192px，四周内边距 10px、边框 1px，按钮宽 170px，两按钮之间保持 8px。外圆角使用 `globals.css` 的 `radius-confirmation-popover`：22px 按钮圆角 + 10px 内边距 + 1px 边框 = 33px，保持内外轮廓平行。外部点击和 `Esc` 收起，`Esc` 优先处理气泡而不关闭父 `Sheet`；打开时聚焦取消按钮，退场时禁用气泡交互，提交期间禁用操作。头像移除的请求与反馈仍由 `AccountDialog` 处理，退出登录使用账号内的原位分列按钮。

## 移除头像确认气泡动画

- 气泡、顶部尖角和内部按钮整体缩放，原点为 `50% -10px`，不额外添加纵向平移。
- 打开初始缩放为 `0.16`、透明度为 `0.12`。缩放关键帧为 `[0.16, 0.27, 0.5, 0.78, 1.018, 1]`；透明度关键帧为 `[0.12, 0.32, 0.65, 0.91, 1, 1]`。两者均为 390ms，时间节点 `[0, 0.2, 0.42, 0.64, 0.88, 1]`，缓动 `[0.22, 0.72, 0.2, 1]`。
- 收回沿同一原点进行。缩放关键帧为 `[1, 0.96, 0.73, 0.39, 0.16]`；透明度关键帧为 `[1, 1, 0.96, 0.68, 0]`。两者均为 210ms，时间节点 `[0, 0.2, 0.46, 0.72, 1]`，缓动 `[0.42, 0, 0.72, 0.35]`。
- 使用用户指定的 Web Animations API 效果：缓动作用于整段时间进度，节点使用 `offset`，不是 Framer Motion 的分段缓动。完整展开、收回保留原关键帧与时长；动画中途切换方向时，先固化当前实际缩放与透明度，再将目标方向的关键帧映射到当前姿态至终点，保持首帧连续，不跳回固定起点。
- 每个气泡独立持有并取消自身动画。完成时先固化最终样式，再取消动画层；收回完成后才通过 `AnimatePresence` 的移除回调卸载。卸载或切换方向时清理当前动画，不取消同元素上的其他动画。
- 动画只随显示/退出状态或减少动态效果设置变化而启动；父组件重渲染、其他弹层打开及移除回调更新不得重启当前动画。完成时调用最新移除回调。
- 系统开启减少动态效果时，直接显示或隐藏；外部点击、Escape、焦点、提交与退出交互禁用仍沿用原实现。

## 退出登录原位确认

- `AccountSignOutControls` 位于账号业务组件内，复用公共 `Button`；第一次点击只展开确认，不提交退出请求。
- 原按钮区域保持总宽度与 44px 高度；左右两半初始各占 50%，以平直内侧边缘无缝拼接成完整胶囊。280ms 内从中心分列为左侧灰色“取消”和右侧红色“确认退出”，两半各缩窄 4px，外侧边缘保持原位，中缝从 0 扩到 8px，内侧圆角从 0 形成半高圆角，最终两侧均为胶囊；分列直接到达目标，不过冲、不回弹。取消用 220ms 沿原路径合回，文字同步淡入淡出，不移动账号面板。展开缓动为 `[0.25, 0.1, 0.25, 1]`，合回缓动为 `[0.25, 0.1, 0.35, 1]`；文字透明度使用同等时长的 `ease-in-out`；这是分列组件的 Framer Motion 过渡，不修改头像气泡的 WAAPI 时间线。
- 完整胶囊与分列后的确认胶囊均不使用彩色阴影，避免阴影被外层收起动画的裁切区域截断；保留现有布局、分列动画与按压参数。
- 这组按钮的按压缩放为 `0.99`，减少宽按钮的下沉感；只覆盖本组控件，公共按钮的默认按压效果保持原样。初始由覆盖完整区域的单一退出按钮承接点击并居中显示文字；展开后由两侧按钮独立承接操作，隐藏入口不参与点击和键盘焦点。
- 展开与合回期间不禁用交互，按当前逻辑状态立即响应操作，可在动画中途取消、重新展开或确认；打开后聚焦取消，合回时聚焦退出入口。Escape 优先取消确认，外部轻点抬起时取消；外部滑动、滚动或被取消的触摸手势保持展开，不在按下时收回。系统减少动态效果时立即切换。
- 退出请求期间两侧禁用，右侧显示“正在退出…”；请求由 `AccountDialog` 处理并防止重复提交，失败保留确认状态以便重试。
- 头像确认气泡展开时点击退出入口，气泡按原有动画收回，退出按钮同时分列。头像气泡的动画参数不变。

## 修改密码原位展开

- `AccountPasswordControls` 在账号安全区复用原 `ActionTile` 入口，标题与钥匙图标留在原位；不再打开嵌套 Sheet。`AccountPasswordForm` 保留原密码校验、当前密码验证、错误映射与其他设备会话撤销流程。
- 卡片内容高度展开、收回均为 360ms，展开缓动 `[0.32, 0, 0.2, 1]`、收回缓动 `[0.4, 0, 0.35, 1]`，起步与结束平缓，无回弹；表单在 90ms 后原位淡入，持续 220ms，不做纵向位移。取消时内容 220ms 淡出，高度立即开始收回；重新展开从当前位置接续。减少动态效果时立即切换。
- 导航排序与退出区域在展开时 160ms 淡出并收起，立即进入 inert；收回时高度同步恢复，140ms 后开始 220ms 淡入。展开前记录账号面板顶部与原内容高度；表单期间保持该位置并保留原内容最小高度，防止过渡帧内容变短将已有滚动位置压回顶部；超出屏幕在面板内部滚动；收回结束恢复普通底部对齐。只在用户点击输入框后打开键盘。
- 三个密码框复用 `PasswordField`；`CredentialForm` 的可选取消操作提供白底细边框、深色文字的取消与蓝色保存两个胶囊，与浅灰表单背景区分。入口不单独做按压缩放；取消与保存按钮仍按压缩小 1%，其他页面沿用各自原按压规则。字段保留独立错误与抖动，整体请求错误出现时平滑调整展开高度。
- 请求期间禁用表单、取消、账号关闭和头像操作；同步 ref 防止重复提交。成功收回并提示，失败保留输入供重试。Escape 优先收回密码表单并保留账号面板。取消或成功时取消输入焦点，退出后的表单不参与点击或键盘焦点。

## 巡检日历滑动切月

- `HistoryCalendar` 使用业务内 `useCalendarPager` 控制水平分页，复用 Framer Motion，不再使用浏览器横向滚动或 CSS 吸附。水平拖动直接改变当前画面位置，容器使用 `touch-action: pan-y` 保留原生竖向页面滚动；点击记录日期、箭头和键盘操作保持原规则。
- 控制器区分待识别手势、正在拖动、正在归位及停稳。水平移动超过 8px 且大于竖向位移后接管；接管立即停止旧归位，从当时实际位置继续跟手，不先走完旧目标，不排队，不设置按钮禁用或手势等待时间。识别水平拖动后取消原生 `touchmove` 默认动作，防止 Chromium 残留原生手势吞掉快滑后的下一次点击；竖向手势不拦截，普通点击不打断归位。
- 每轮手势以接管时最接近的月份为基准，最多前进或后退一个月；后续手势无需等待旧动画结束。低速松手停到最接近的页面；最近约 80ms 的水平速度达到 0.65 页/秒时，结合本轮位移方向选择相邻月份。本轮途中反向时向已跨过的边界返回，不强制走到原定月份。
- 松手归位复用 Framer Motion 弹簧，刚度 420、阻尼 `2 * sqrt(420)`，初速度来自本轮松手速度。初速度只沿目标方向保留，并限制到 `sqrt(420) * 剩余距离`，防止越过目标或先反向移动。归位时长随剩余距离和速度变化，没有过冲回弹；遵从减少动态效果设置，直接定位最终页。
- 月份标题按当前画面最接近的页面更新：拖动跨过半页显示下一月份，反向退回则恢复，不新增标题动画。停稳后才向父组件提交月份。新的横向手势、箭头或外部导航会使旧动画完成回调失效，普通重渲染不得用尚未提交的旧月份覆盖当前画面或标题。
- 当前可见月份前后各三个月预渲染，最多七页；六行日期区保持稳定，每行至少 44px。各月以首次打开的月份为固定坐标原点，窗口补充或移除月份时不改变已存在页面的位置及正在运动的坐标，避免翻到第三页后重新定位或自动翻月。
- 非当前月份使用 `inert` 和 `aria-hidden`，不参与日期点击或键盘焦点。容器使用 `overflow-clip`，防止聚焦日期时浏览器改变隐藏滚动坐标而偏移画面。原有周一首日、记录标记、今日样式保持不变。点击有记录日期先定位并提交所属月份，再打开原详情，返回日历保持一致。水平拖动结束产生的点击会被拦截，下一次独立点击立即有效。
- 最早记录月份不渲染更早的页面，继续隐藏上个月箭头；拖动坐标与目标月份均限制在该边界。原箭头和外部月份导航立即定位，不新增动画。横向触控板输入同样跟随画面，100ms 无后续输入时归位；该检测仅划分滚轮手势，不是交互锁。横向拖动中视口尺寸变化或手势取消时归位到最近月份；卸载时停止动画和计时器。

## 验证

运行 `npm run lint`、`npx tsc --noEmit`、`npm test` 和 `npm run build`。`tests/shared-ui.test.mjs` 检查自定义字号与文字颜色能同时保留，以及公共组件的错误关联、选择语义、弹层标题关联和表单结构；动画、实际计算字号、焦点循环、关闭后焦点状态、`Esc` 关闭和滚动锁定还需浏览器检查。

日历回归检查须覆盖 Chromium 与 WebKit：双向连续十二页、翻两页后停顿再翻第三页、快速重复及反向手势，停稳后标题、日期网格与父组件月份须一致，且不得自行翻月；页面数量最多七个，六行高度保持不变。检查日期点击、拖动后误点击、键盘、竖向滚动、最早月份限制、跨年、尺寸变化和减少动态效果。

归位接管检查：在上一轮约 90% 到位时继续向下一页滑动，新输入须立即从当前画面位置跟手，足够速度或距离时进入下一页；反向输入须可返回上一页，旧完成回调不能覆盖新结果。`tests/calendar-paging.test.mjs` 检查目标判定、接管、反向、边界及无过冲的初速度限制；真实触摸手感仍需 iPhone / Android 真机验收。

## 历史菜单滚动稳定性

历史汉堡菜单根容器使用 `overflow-anchor: none`，避免 iPhone 浏览器在 SVG 线条变形时补偿页面滚动位置。保留原有路径变形、透明度、时长与曲线；仅排除菜单子树，不关闭整页滚动锚定。

## 详情删除原位确认

- `DetailRecordActions` 替代详情底部直接打开删除弹窗的入口；默认保留左侧蓝色返回胶囊、右侧浅红删除圆形，48px 高、8px 间距、固定总宽度及原有安全区。
- 点击删除后，右侧圆形向左扩宽为红色“确认删除”胶囊，左侧同步收窄、变为灰色“取消”胶囊；最终等宽，无阴影、无纵向位移。展开 280ms，缓动 `[0.25, 0.1, 0.25, 1]`；取消沿原路径恢复 220ms，缓动 `[0.25, 0.1, 0.35, 1]`，无回弹，文字与图标同步交叉淡入淡出。保留公共按钮按压反馈。

- 二次确认复用历史记录的删除与撤销逻辑；批量删除保持原弹窗。按钮组件按记录重新挂载，离开详情不保留确认状态。
